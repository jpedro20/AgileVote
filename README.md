# AgileVote

**AgileVote** is a web-based Scrum Poker application designed to help agile teams estimate user stories collaboratively and efficiently.

With AgileVote, teams can create estimation rooms, invite participants and vote on user stories in real time.

---

## 🚀 Features

- Create and manage estimation rooms
- Share room links with team members
- Real-time voting
- Anonymous voting until reveal
- Vote reveal & consensus discussion
